# Помесячная статистика (зп + часы) — интервью требований

Статус: интервью завершено. Реализационно влияющих неизвестных нет.
Следующий шаг — по команде пользователя «напиши спеку».

## Контекст задачи

Пользователь хочет видеть **статистику за предыдущие месяцы — заработок и часы**. Сейчас на вкладке
«Графики» есть столбчатый «Помесячный доход» с тултипами (часы/дни видны только при наведении), но
**отдельной таблицы с числами по месяцам нет**.

Связанная фича: [график прогноза с прокруткой в прошлое](../../forecast/timeline-scrollback/timeline-scrollback-requirements.md).

### Найденные паттерны

- Данные по месяцам уже готовы (`monthlyAgg`); нужно только отрисовать таблицу.
- Таблицы в проекте: `<div class="scroll"><table>…</table></div>` с `th.num` для чисел
  (см. рабочие/расходные/чекпоинт-таблицы).
- Доход = `hours*rate` (gross), как и в `monthlyAgg.amount` и помесячном графике.

### Подтверждено из кода

- Источник истины — `monthlyAgg(state.entries)`; «зп» = `amount` (часы×ставка, gross), что совпадает
  с уже существующим помесячным графиком (внутренняя согласованность).
- Валюта — `cur()`; формат месяца — `monthRu('YYYY-MM')`; чисел — `fmt`.

### Не выводится из кода (требовало решения)

- Форма представления и место (см. вопрос 3).
- Что считать «зп» (см. вопрос 4).

## Вопросы и ответы

3. **Где и как показать статистику по месяцам?**
   Почему важно: определяет разметку и место рендера.
   Ответ: **таблица на вкладке «Графики»**.

4. **Что показывать как «зп» за месяц?**
   Почему важно: определяет формулу.
   Ответ: **заработано = часы × ставка** (gross, как в помесячном графике).

## Подтверждённые решения

- Новая **таблица на вкладке «Графики»** с колонками по месяцам:
  **Месяц · Часы · Доход (заработано) · Рабочих дней**.
- Источник — `monthlyAgg(state.entries)`; «Доход» = `amount` (часы×ставка, gross), валюта `cur()`.
- Рендер встроить в `drawAllCharts` (или отдельную `renderMonthlyStats`, вызываемую оттуда),
  чтобы таблица обновлялась при открытии вкладки и после изменения данных.

## Дефолты (приняты, не требуют отдельного вопроса)

- **D1 (порядок).** Месяцы сверху вниз — **от свежих к старым** (последний месяц первым: «за
  предыдущие месяцы»).
- **D2 (текущий месяц).** Текущий (неполный) месяц показывается как обычная строка, без спец-пометки.
- **D3 (формат).** Часы — `toFixed(1)`; доход — `fmt(amount)` + `cur()`; месяц — `monthRu`.
- **D4 (пусто).** Нет записей → карточка/таблица скрыта либо показывает «нет данных» (как другие
  карточки графиков, через `setCardEmpty`/скрытие).
- **D5 (без налога).** Показывается gross-доход; чистыми после налога не выводим (по ответу 4).
- **D6 (итог).** Допустимо (но не обязательно) добавить строку/подпись с суммой за весь период —
  решается на этапе спецификации, поведение по умолчанию: без итоговой строки.
