Расписание зарплаты

День зарплаты закрывает период часов и по умолчанию является датой прихода денег.

До четырёх дней, значения 1–28.

Исключения из расписания

Отметь реальную дату прихода и, при необходимости, отдельную границу учтённых часов.

Резервная копия

Состояние сохраняется в браузере автоматически.

Синхронизация GitHub Gist

Приватный gist переносит одно состояние между устройствами.

Как подключить

Создай GitHub token с единственным разрешением gist. На первом устройстве создай gist, на остальных укажи его ID и выбери «Связать».

Токен хранится в браузере. Держи gist приватным и отзови токен, если устройство потеряно.
