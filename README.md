# Финансовый помощник

Однофайловое (теперь — модульное) веб-приложение для анализа дохода из Clockify и прогноза накоплений.

**Открыть:** [https://maksimlevchenko.github.io/clockifyAnalyzer/](https://maksimlevchenko.github.io/clockifyAnalyzer/)

## Что умеет

- Импорт CSV/PDF-отчётов Clockify (Detailed report); догрузка без дублей.
- Ручное редактирование/удаление любой записи через диалог; групповые операции по фильтру (даты, проект, дни недели).
- Расходы трёх типов: ежемесячные (по числу), ежедневные (равномерно распределённая сумма за месяц), разовые (по дате).
- Разовые поступления, чекпоинты баланса, дни зарплаты («день зп» — отсечка часов; деньги по умолчанию приходят в тот же день) и фактические даты выплат (пары «день прихода денег + день учёта часов» — для месяцев, где день прихода свой).
- Прогноз накоплений (Monte Carlo, 5000 симуляций) с калибровкой по будущим чекпоинтам и зубчатой моделью выплат. Интерактивный график масштабируется колесом, щипком, кнопками и готовыми периодами, листается перетаскиванием и показывает фильтруемые события: расходы, пополнения, выплаты, даты учёта часов, чекпоинты, цели и нерабочие дни.
- Несколько графиков (доход по дням / часам / месяцам / проектам / дням недели, гистограмма, баланс по чекпоинтам, помесячный прогноз, распределение финального баланса) + таблица помесячной статистики (часы и заработок по месяцам).
- Все данные хранятся в `localStorage` браузера. Экспорт/импорт состояния в JSON.

## Локальный запуск

Никакой сборки нет. Просто открой `index.html` в браузере — всё уже работает.

```
git clone https://github.com/MaksimLevchenko/clockifyAnalyzer.git
cd clockifyAnalyzer
# открыть index.html двойным кликом или
start index.html       # Windows
open index.html        # macOS
xdg-open index.html    # Linux
```

## Деплой на GitHub Pages

1. Settings репозитория → **Pages**.
2. **Source**: `Deploy from a branch`, **Branch**: `main`, папка `/ (root)` → Save.
3. Через 30–60 сек на этой же странице появится URL.

Любой `git push` в `main` автоматически передеплоит сайт.

## Структура проекта

```
index.html          — разметка + подключение скриптов
styles.css          — все стили
js/
  core.js           — чистые функции (CSV/PDF, агрегации, модель прогноза)
  state.js          — state, persistence, anchor-чекпоинты
  ui.js             — toast, табы (hash-роутинг), тултип
  charts.js         — отрисовка canvas-графиков
  app.js            — обработчики DOM + render-функции + init
```

## Приватность

Отчёты и личные данные (часы, ставки, балансы) не отправляются на сервер и живут в `localStorage` твоего браузера. Для чтения PDF при первом PDF-импорте браузер загружает PDF.js с CDN, сам выбранный файл остаётся локальным. Чтобы перенести данные на другое устройство — кнопка «Экспорт в файл» на вкладке «Данные».
