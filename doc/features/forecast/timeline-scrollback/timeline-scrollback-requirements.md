# График прогноза: старт с сегодня + прокрутка в прошлое — интервью требований

Статус: интервью завершено. Реализационно влияющих неизвестных нет.
Следующий шаг — по команде пользователя «напиши спеку».

## Контекст задачи

Сейчас график прогноза на вкладке «Прогноз» рисуется целиком от **якорного чекпоинта**
(последний фактический чекпоинт ≤ сегодня) до даты конца прогноза. Якорь часто лежит в прошлом,
поэтому слева от сегодняшнего дня тянется уже известный/калиброванный отрезок, и «сегодня» теряется
где-то в середине. Пользователь хочет, чтобы **обзор по умолчанию начинался с сегодня** (фокус — будущее),
а прошлое можно было **листать назад** перетаскиванием, причём **дальше якоря** — в реальную историю.

Связанная фича: [помесячная статистика](../../charts/monthly-stats/monthly-stats-requirements.md).

### Найденные паттерны

- Прогноз и его метрики целиком завязаны на якорь; «начать от сегодня» в самой модели невозможно
  без чекпоинта на сегодня → это про **видимую область графика**, а не про расчёт.
- Дневной поток в прошлом уже выводим из `cashFlowFromCheckpoints` (заработок + поступления −
  введённые расходы − неучтённый остаток), интервал за интервалом между фактическими чекпоинтами.
- Все графики — статичные canvas, перерисовка целиком; интерактивность ограничена hover-тултипом.

### Подтверждено из кода

- «Старт — только сегодня» = дефолтная **видимая область** `[сегодня … конец]`; модель и калибровка
  не меняются.
- Реконструкцию баланса в прошлом можно сделать **детерминированно** из фактических данных, привязав
  её к известным балансам чекпоинтов (чтобы линия проходила через каждый фактический чекпоинт).
- Раньше **первого фактического чекпоинта** баланс неизвестен → естественный левый предел прокрутки.

- Механизм прокрутки (см. вопрос 2).

## Вопросы и ответы

1. **Что значит «старт — только сегодня»?**
   Почему важно: определяет, меняем ли модель или только обзор.
   Ответ: график прогноза; **«можно смотреть и до якорей»** — обзор по умолчанию с сегодня, но
   прокрутка назад должна показывать прошлое в т.ч. **левее якоря**.

2. **Как листать график назад?**
   Почему важно: определяет объём работы (инфраструктуры панорамирования нет).
   Ответ: **тянуть мышью/пальцем** (drag-pan по канвасу).

3. **Применять только к прогнозу или ко всем графикам?**
   Ответ (из выбора): к графику прогноза. (Графики по дням — отдельная фича; здесь не трогаем.)

4. **Что показывать левее якоря, где прогноза нет?**
   Почему важно: определяет новый расчёт и источник данных.
   Ответ: **реконструкция баланса по дням** (восстановить дневной баланс назад от якоря:
   баланс − доход + расходы), а не просто линия по чекпоинтам.

## Подтверждённые решения

- **Видимая область по умолчанию**: `[сегодня … конец прогноза]`. Сам расчёт прогноза
  (`forecastSavings`, якорь, калибровка, метрики, сводка) **не меняется**.
- **Прокрутка**: перетаскивание мышью/пальцем по графику прогноза `ch-fc` влево/вправо.
- **Левее якоря — дневная реконструкция баланса** из фактических данных. Реконструкция привязана
  к фактическим чекпоинтам: на каждом интервале между соседними фактическими чекпоинтами линия идёт
  от баланса A к балансу B, форма задаётся дневным фактическим потоком (доход + поступления −
  введённые расходы − равномерно распределённый неучтённый остаток интервала), и проходит **точно**
  через каждый чекпоинт.
- **Прошлое vs прогноз** визуально различаются: реконструкция (прошлое) — отдельным стилем
  (например, сплошная «фактическая» линия без полосы 80%), прогноз (будущее) — как сейчас
  (среднее + полоса). На стыке (якорь) линии сходятся в балансе якоря.
- **Маркер «сегодня»** на графике (вертикальная линия), чтобы при прокрутке было видно границу
  факт/прогноз.

## Дефолты (приняты, не требуют отдельного вопроса)

- **D1 (левый предел прокрутки).** Назад можно листать до **первого фактического чекпоинта** —
  раньше баланс неизвестен, реконструкция невозможна.
- **D2 (правый предел).** Вправо — до **даты конца прогноза** (`fc-end`); дальше горизонта нет.
- **D3 (масштаб).** Px-на-день фиксируется по дефолтному окну `[сегодня … конец]` (та же плотность,
  что и при текущем полном рендере, но окно начинается с сегодня); при прокрутке масштаб сохраняется.
- **D4 (нет чекпоинтов до якоря / якорь == первый чекпоинт).** Реконструировать нечего → влево
  прокрутка ограничена якорем (текущее поведение «прошлого» = пусто слева от якоря).
- **D5 (today вне диапазона).** Если `сегодня > конец` (горизонт целиком в прошлом) — окно по
  умолчанию прижимается к правому краю (`[конец−окно … конец]`), без ошибок.
- **D6 (touch).** Drag-панорамирование на touch должно сосуществовать с тач-тултипом
  ([ui.js:69-71](../../../../js/ui.js#L69-L71)); приоритет горизонтального драга над тултипом
  решается на этапе спецификации.
- **D7 (сброс вида).** При перестроении прогноза (смена даты/якоря/параметров) вид возвращается к
  дефолтному окну `[сегодня … конец]`.
